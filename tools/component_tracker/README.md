# Lab Component Tracker

**Owned by**: `docs-tracker-agent`

Tracks lab borrowed components under the **15/60-day ID rotation policy** across team members:
- **Krishna** (Lead, Hardware & Integration)
- **Aditya** (Hardware / Chassis)
- **Parth** (Software)

### 4-Sheet Structure for `lab_component_tracker.xlsx`:
1. **Entry**: Paste-and-parse component checkouts and returns.
2. **Rotation Log**: Timestamped borrower transitions with remaining days.
3. **Dashboard**: Summary showing active holder per item, flags for 15-day limit approaching.
4. **Policy Reference**: Rules and rotation constraints.
